FAQ

A personal, all-in-one dashboard for tracking online certifications, university coursework, daily expenses, and tasks. Built as a single-page vanilla web app — no frameworks, no build tools. All data stays in your browser.
All structured data (courses, tasks, expenses, settings) is stored in localStorage. Journal images are stored in IndexedDB (studyDB → images store). Nothing is sent to any server.
Go to Settings → General and use the Export button to download a .json file. To restore, use the Import button and select your backup file. This will overwrite all current data.
Analytics aggregates data from four features:
  • Courses — completion progress per phase/role
  • Study — weekly checklist progress + pie chart (Jurusan vs MKU)
  • To-do — completion rate, priority and category distribution
  • Finance — weekly total spending trend and category breakdown
Open the Courses tab. Use the filter bar to narrow by Role (FullStack, Software, AI Engineer, Others), Category, or Company. Click the checkbox to mark a course as completed. You can also add custom courses using the + button at the top of the table.
Click the + Add Course button above the courses table. Fill in the name and select a role. Custom courses are saved to localStorage and appear alongside the built-in courses. You can archive or delete them at any time.
Each course row has a ⚙️ button. Click it and select Archive. The course moves to the Archived tab. From there you can Restore it back to the active list or Delete it permanently.
Go to the Certificate tab and click the + button. Fill in the title and upload an image. Each certificate card shows the title, date, and a preview of the uploaded image. You can delete certificates from the ⚙️ dropdown.
When you check off a university class in the Study tab, a modal opens where you can write a title and summary of what you learned, and optionally upload an image. After saving, the entry appears in the Journal tab as a masonry card. Journal entries persist even after the weekly reset.
No. Only the Study checkboxes reset every Sunday at 23:59 WIB. All your Journal entries (notes, summaries, images) remain saved and accessible in the Journal tab. You can filter them by week using the dropdown.
Click any card in the Journal masonry grid to open a detail modal showing the full entry content and image. From the detail modal you cannot edit, but you can see the complete record. Use the week filter dropdown to browse entries from previous weeks.
The To-do tab supports full CRUD. Click + to add a task with a name, category, priority (Low/Medium/High using the button group), and optional due date. Use the search bar to find tasks, and the category/priority dropdowns to filter. Click the checkbox to mark a task as done.
Go to the Finance tab and click Add Expense. Fill in the amount, select a currency from the dropdown (18 currencies available), choose a category (Food, Transport, Shopping, etc.), add an optional description, and pick the date. The weekly summary updates immediately.
18 currencies are supported: IDR (Rp), USD ($), EUR (€), GBP (£), JPY (¥), SGD (S$), MYR (RM), AUD (A$), THB (฿), PHP (₱), KRW (₩), CNY (¥), INR (₹), SAR (﷼), AED (د.د), BND (B$), BRL (R$), and VND (₫). Each transaction stores its own currency.
Click the Export button next to the Finance table heading. A modal opens where you can choose CSV (opens in spreadsheet apps) or PDF (generated via jsPDF with a formatted table for the current week).
Open Settings → General. Under Theme, choose Light, Dark, or System (follows your OS preference). The change saves automatically.

About

Personal Habit Tracker — a personal, all-in-one dashboard by Alfiz Ilham for tracking learning progress, university coursework, daily expenses, and tasks. Built as a single-page vanilla web app with no frameworks or build tools.

Tabs

Tab Purpose
Courses Track online certifications — filterable by Role, Category, Company
Analytics Charts and progress bars aggregating Courses, Study, To-do, and Finance data
Certificate Gallery of earned certificate images
Study Weekly university class schedule with a checklist that resets every week
Journal Masonry-grid log of study notes/materials tied to each class
To-do General task list with priority and category filters
Finance Weekly expense tracker with per-transaction table, daily report, and charts
Archived Courses removed from the active list but kept for reference

Data & Privacy

All user data is stored in NeonDB (PostgreSQL cloud). Local storage is used as a cache for fast reads. Nothing is shared with third parties. Data can be exported via Settings → Export.
